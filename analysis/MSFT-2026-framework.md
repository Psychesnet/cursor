## 1. Known｜熟悉度評估

**商業模式清晰度：高。** 收入拆分到產品線、客戶類型與合約能見度都可直接從 10-K / 財報對上。

### 1.1 業務模式與產業鏈位置

Microsoft 同時站在企業軟體棧的**應用層、平台層與基礎設施層**：

| 層級 | 角色 | 對應產品 | 產業鏈位置 |
| --- | --- | --- | --- |
| 應用 / 工作負載 | 向企業與消費者賣訂閱與廣告 | Microsoft 365、Dynamics 365、LinkedIn、Search、Xbox | 靠近終端用戶，轉換成本高 |
| 平台 / 開發者 | 賣工具、控制面與用量 | GitHub、Foundry、Fabric、Agent 365、Copilot | 鎖住開發者與企業資料 |
| 基礎設施 | 賣算力、儲存、網路與模型推論 | Azure IaaS/PaaS、自研 Maia / Cobalt | 與 AWS、Google Cloud 直接競爭的 hyperscaler |

這不是「單一雲端公司」或「單一 Office 公司」。FY2026 的成長幾乎全部來自**雲 + AI 基礎設施**與**既有座位數上的 AI 加價**，傳統授權 / 硬體只負責現金流與入口，不再是增長引擎。

**成長標準判定：**

- **達到 10% 門檻：是**（18% / 16% CC）
- **達到 20% 門檻：否**（差 2 個百分點；但 Intelligent Cloud +29.7%、Azure +41% 已遠超 20%）

對一個 $3,300 億營收的公司來說，18% 是「大型複合增長」而不是早中期爆發。增量絕對值才是重點：一年多做了 **$501 億** 營收，其中約 **90%** 來自 Server/cloud 與 M365 Commercial。

| --- | --- | --- | --- |

大 M 的意義：Microsoft 不是在一個即將見頂的 $300 億利基裡搶份額，而是同時吃「企業軟體」與「AI 資本開支」兩條萬億級曲線。

#### SAM｜Microsoft 實際可吃到的市場

| 可服務範圍 | 現況 | 含義 |
| --- | --- | --- |
| Azure 對應的雲基礎設施 SAM | TTM $5,000 億 × 20% ≈ **$1,000 億** | 與「Azure 破 $1,000 億」完全對得上，代表市佔口徑不是行銷數字 |
| Microsoft Cloud（含 M365 / Dynamics / LinkedIn 商業雲） | 已做 **$2,144 億** | 這是「已佔領的 SAM」，不是潛在 |

**市場結構判斷：** 大 M 極大且在加速；小 M（雲基礎設施）正在被 AI 重新加速到 40%+；Microsoft 的 SAM 已經很大，下一階段是**在已佔領的席位上提高 ARPU**，以及在 20% 的雲市佔上搶 AI 推論份額，而不是從零開拓市場。

### 2.5 增長持續性

**支持延續的硬證據：**

| 指標 | 數字 | 解讀 |
| --- | --- | --- |
| 商業 RPO（已簽約未認列） | **$6,780 億**，YoY **+84%** | 加權存續 **2.3 年**；約 **30%（~$2,030 億）** 會在未來 12 個月認列，近端部分 YoY +37%；12 個月以外部分 **+112%** |
| 剔除 OpenAI 的 RPO | 仍 **+25%** | 不是只有一家模型公司在簽長約 |
| 當季 RPO 環比增量 | **全部來自非 frontier model 客戶** | 集中度風險仍在，但邊際增長已在分散 |
| Microsoft Cloud 全年 | 近 **90%** 來自非 frontier model 客戶 | 已實現營收比 backlog 更分散 |
| 產能 vs 需求 | 「customer demand continues to exceed available capacity」 | 短瓶頸是供給不是需求 |
| 產能擴張 | FY26 新增 88 座資料中心；Q4 再加 31 座、1 GW；兩年內產能將近翻倍 | 供給正在追上 |
| 合約外未開工租賃 | **$3,291 億** 資料中心租賃尚未開始（FY27–FY33） | 管理層已把未來產能鎖在表外承諾裡 |

**可能打斷高增長的點：** OpenAI 合約的同比比較會讓 bookings / RPO 增速「一季高一季低」；若 Azure 增速從 43% 掉回 25%，整家公司營收就會回到低 teens。目前指引是 Q1 FY27 Azure 還要再加速到 45%，至少未來兩個季度看不到失速。

**增長結論：** 動能強、賽道在擴張、能見度高。這是「大型複合增長」而不是「早期指數增長」。未來 3 年共識卡在 16–19%，剛好卡在 10% 達標、20% 未達的區間。

**為什麼三個倍數結論不一致：**

- PE 看起來合理，是因為淨利率 40%，市場在買「已賺到的獲利」。
- PS 貴，是因為市場願意為 68% 毛利、47% 營業利益率付溢價。
- P/FCF 貴，是因為 FY2026 自由現金流只有 **$670 億**（營運現金 $1,829 億 − 資本支出 $1,159 億），FCF 率從歷史 25%+ 掉到 **20.2%**，而且日曆 2026 capex 還要再上到約 $1,750 億。

**行業對比結論（綜合）：** 用盈利看是**合理偏低**；用現金流看是**高估**。現在的估值本質上是「市場相信 capex 會在 2–3 年內轉成折舊可控的高增量利潤」。

### 3.3 合理 PE 給予範圍

給 28–32x，中樞 **30x**。依據：

1. **增長配得上：** 營收 CAGR ~18%、EPS CAGR ~16%，不是 8% 的公用事業股，不該只給 18–20x。
2. **質量溢價：** 營業利益率 47%、ROIC 26%，同業少見；歷史上 MSFT 在 2024–2025 多數時間走在 30–36x trailing。
3. **護城河與地位：** Azure 穩居第二、M365 近乎標準、身份 / 開發者 / 資料層轉換成本極高。
4. **必須打折的地方：** FCF 被 capex 壓住、OpenAI 相關方風險、折舊即將上升。因此不給 35x 以上的「AI 故事倍數」，而是從歷史中樞往下修 3–5 個點。

| 情境 | 合理 PE | 適用條件 |
| --- | --- | --- |
| 保守 | 26x | Azure 掉到 25%、FCF 不再回升 |
| 基準 | **30x** | Azure 維持 30%+ 兩年、營業利益率守住 45%+ |
| 樂觀 | 32x | Copilot 滲透率大幅跳升、capex 佔營收比開始下降 |

## 5. Moat｜護城河評估

評分 0–1.0，五項加總滿分 5.0。

### 5.1 成本優勢｜0.80

- 軟體側具備教科書級規模經濟：PBP 營業利益率 59.9%，銷售與管理費用佔營收僅約 10%。
- 雲側單位成本正在改善：Nadella 稱 Maia 200 每美元效能比現有硬體好 **30%**；自有模型在 Excel / PowerPoint / Dynamics 上把 GPU 成本砍了 80%+；Copilot 工作負載吞吐量一年內提升 4 倍。
- 反向證據：FY2026 資本支出 **$1,159 億**（佔營收 35%），Intelligent Cloud 銷貨成本增速快於營收，輕資產故事已結束。
- 結論：軟體端成本優勢極強，雲端是「規模優勢換資本開支」，不是輕資產。

### 5.2 網絡效應 / 轉換成本｜0.90

- **M365：** >4.5 億商業付費席，檔案、身份、合規、Teams 綁在一起。換 Google Workspace 不是換套件，是換公司作業系統。
- **Identity + 資安 + Agent 365：** 推出兩個月就有近 **4,000 萬** agents 註冊。代理層會繼承既有 Entra / Purview 治理，後來者更難挖牆腳。
- **GitHub：** 2.25 億用戶，1/3 的 pull request 已有 agent 參與。開發者圖譜本身就是網絡。
- **LinkedIn：** 約 13 億會員的雙邊市場（求職者 ↔ 企業招聘 / 廣告），幾乎沒有同等替代。
- **Azure Marketplace / 資料重力：** 企業把資料放進 Fabric / Cosmos / PostgreSQL 後，推論自然留在 Azure。PostgreSQL 營收 +55%，且同時使用 Foundry 的客戶 +80%。

轉換成本高、網絡效應真實，但雲基礎設施本身網絡效應弱於應用層（工作負載可以 multi-cloud）。給 0.90 而不是 1.0，是因為 AWS / Google 仍能在 IaaS 層挖走增量。

### 5.3 品牌優勢｜0.90

- Interbrand Best Global Brands **2025 第 2 名**，品牌價值 **$3,885 億**（+10%），僅次於 Apple $4,709 億。  
  來源：[Interbrand](https://interbrand.com/best-global-brands/global/microsoft/)
- 在企業採購裡，「Microsoft 365 / Azure / Active Directory」經常是預設短名單，不是需要教育市場的新品牌。
- Windows 全球桌面 OS 佔有率 **71.2%**（Statcounter 2026-07）。  
  來源：[Statcounter](https://gs.statcounter.com/os-market-share/desktop/worldwide/)
- 扣 0.10：消費端 Copilot 品牌仍不如 ChatGPT 直覺；搜尋品牌仍遠弱於 Google。

### 5.4 技術門檻｜0.80

- FY2026 研發 **$356 億**（+9%），規模本身就是門檻。
- 全棧能力：自研 Maia（GPU 類）+ Cobalt（CPU）+ 資料中心 + 11,000+ 模型目錄 + 自有 MAI 模型家族。這不是「轉售 OpenAI API」的公司。
- 與 OpenAI 的合約給 Microsoft **模型與基礎設施 IP 整合權**，同時持股約 25%。這是獨特資源，但也是單點依賴。
- Foundry 客戶 10 萬、年化 1 兆 token 客戶數 ×4；Fabric 付費客戶 4 萬（+60%）。
- 扣分：基礎模型領先地位不在 Microsoft（在 OpenAI / Google / Anthropic）；自研模型是「夠好、夠便宜」策略，不是絕對技術壟斷。專利數量對雲 / AI 競爭的解釋力也有限，故不把專利當作主證據。

### 5.5 業務韌性｜0.80

**加分：**

- 三大部門、十條產品線；FY26 無單一客戶或（除美國外）單一國家營收超過 10%。
- 美國 / 海外營收接近 51/49。
- 淨現金、利息覆蓋 51x、有效稅率穩定。
- 已實現雲收入的 ~90% 來自非 frontier 客戶。

**扣分：**

- 增量高度集中：兩條產品線貢獻 90% 增長。
- OpenAI 相關收入 $241 億、RPO 增速若剔除 OpenAI 會從 +84% 降到 +25%——**存量營收不集中，增量能見度集中**。
- Xbox / Windows 已連續走弱，消費端不再是緩衝墊。
- IRS 對 2004–2013 年移轉訂價追稅 **$289 億 + 罰息**（公司否認，但仍是或有負債）。

## 6. Risks｜主要風險

1. **AI 資本開支無法如期變現**  
   FY26 capex $1,159 億，日曆 2026 還要到約 $1,750 億；未開工租賃 $3,291 億。若 Azure 用量或價格不如預期，折舊會先打營業利益，FCF 再往下。這是目前估值最大的基本面風險。

2. **OpenAI 相關方集中**  
   FY26 來自 OpenAI 的收入 $241 億、應收 $60 億、持股約 25%。RPO 同比 +84% 裡有很大一塊是這張長約。OpenAI 若自建雲、轉單、或出現財務壓力，Microsoft 的 bookings 與 Azure 增速會立刻失真。公司已在降低模型單點依賴（自研 MAI、引入 Anthropic / Mistral / xAI），但合約層仍重。

3. **雲端競爭：Google 在搶份額，AWS 規模仍大**  
   Q2’26 市佔 AWS 28% / MSFT 20% / GOOG 15%。Google 一年拿下 2 個百分點；CoreWeave、Oracle、neocloud 在 GPU 雲上增速更快。Azure 不是在真空裡跑 43%。

4. **產能不足本身也是風險**  
   管理層連續說需求大於供給。短線這是好事，長線代表有訂單被推走、客戶被迫 multi-cloud。效率提升（dock-to-live 時間近乎減半）是在補這條裂縫，不是裂縫已消失。

5. **毛利率與折舊會計**  
   FY27 起資料中心耐用年數從 15 年改 25 年，帳面 capex / 折舊會變好看，**現金流出不變**。市場若把會計緩和誤認為資本週期結束，後續修正會很痛。

6. **消費與 PC 週期**  
   Windows OEM -7%、Xbox -10%。這兩塊不再能在企業 IT 放緩時當避風港。若企業 IT 預算也被 AI 專案排擠（只買 Azure、不升級 E5），PBP 的 16% 也會降速。

7. **監管、反托拉斯與稅務**  
   歐美對雲、綁售、瀏覽器、AI 安全的審查持續；IRS NOPA $289 億是具體數字，不是敘事。愛爾蘭營運中心的有效稅率優勢也可能被全球最低稅改削弱。

8. **資安與平台濫用**  
   10-K 把 cyberattack、資料外洩、AI 濫用列為核心風險。身份系統出大事，護城河會反向變成系統性風險。

9. **總經與利率**  
   企業軟體對 IT 預算週期敏感。利率若再次上升，未開工的 $3,291 億租賃與融資租賃利息（FY26 利息已升至 $30.5 億）會同步變貴。

10. **執行與人才**  
    自研晶片、自研模型、資料中心建設、代理人平台同時推進。任何一條線交付落後，43% 的 Azure 增速就守不住。

## 7. Summary｜綜合分析與觀點

### 7.1 評估結果清單

| 面向 | 標籤 |
| --- | --- |
| 增長 | **增長優異（大型複合增長）** — 總營收 +18% 過 10%、不過 20%；Azure +41%、RPO +84% |
| 估值 | **價值空間充足（基準 +44%）** — PE 合理偏低，P/FCF 偏貴 |
| 護城河 | **高護城河（4.20 / 5.00）** |
| 盈利 | **盈利能力卓越** — 毛利 68%、營業利益率 47%、ROIC 26%、利息覆蓋 51x |

### 7.2 綜合分析

Microsoft 目前是全球少數能同時擁有「企業預設入口」與「AI 基礎設施規模」的公司：FY2026 營收 $3,318 億（+18%），其中 Microsoft Cloud $2,144 億（+27%）、Azure 破 $1,000 億（+41%），增量的九成來自 Server/cloud 與 M365 Commercial。增長能見度來自 $6,780 億商業 RPO 與仍供不應求的 GPU/CPU 產能，而不是行銷故事。盈利端幾乎沒有同業對手——47% 營業利益率、26% ROIC、淨現金——但現金流端已經換成「重資產 hyperscaler」的臉：FCF 掉到 $670 億，P/FCF 53x，日曆 2026 capex 還要再上。估值用盈利看是合理偏低（trailing 27x、forward 24.5x，低於軟體業中位 37x，也低於多數巨型同業），用三年平均預期 PE 20.9x 對合理 30x，基準上漲空間約 44%。最大隱憂不是需求消失，而是**資本週期與 OpenAI 合約節奏**：如果 43% 的 Azure 只是產能釋放的一年，或 OpenAI 長約的同比貢獻退去後核心雲增速回到 25%，市場會立刻把倍數從「複合增長股」切回「貴的現金流股」。

**標的類型：AI 基礎設施驅動的大型趨勢成長股（quality compounder），不是價值股，也不是純 SaaS 現金牛。**  
適合的持有邏輯是「用合理 PE 買 15–18% 的可見增長 + 高護城河」，而不是賭倍數擴張或短線 FCF 爆發。

## 8. 商業模式 × 未來展望：客人是誰、錢花在哪、成長怎麼來、該盯什麼

這一節把前面的財報數字收成一條經營邏輯：**誰在付錢、錢買的是什麼、Microsoft 自己的錢砸去哪、未來成長靠哪一層計價、以及哪些數字一變就代表故事裂了。** 主要依據 FY26 Q4 財報會與 10-K，不是推論。

### 8.1 客人是誰

未來三年，Microsoft 的「客人」不是一個均質的企業客戶，而是四層、付錢方式完全不同的人。層級愈上面，單客金額愈大、波動愈高；層級愈下面，基數愈大、ARPU 愈低、但決定席位增長。

| 層級 | 客人是誰 | 現況規模 | 他們買什麼 | 未來角色 |
| --- | --- | --- | --- | --- |
| A. 前線模型公司 | 以 OpenAI 為主的 frontier labs | FY26 相關收入 **$241 億**（約總營收 7.3%）；Cloud 已實現收入裡約 **10%** 來自這類客戶 | Azure GPU/CPU 用量、長約容量 | **增量能見度的放大器，不是利潤錨。** RPO +84% 若剔除 OpenAI 只剩 +25%；當季 RPO 環比增量已全部來自非 frontier |
| B. 大型企業知識工作者 + IT / 資安 | Fortune 500、跨國金融、顧問、醫療、政府 | Copilot 付費席 **>3,000 萬**；>5 萬席客戶數 YoY **×7**；NHS 50.5 萬、KPMG 27.6 萬、HSBC 20 萬、EY E7 40 萬 | M365 席位、E5/E7、Copilot、Azure、資安、Agent 365 | **未來主戰場。** 從「買座位」變成「座位 + token 用量」；E7 上市兩個月已有數百萬席 |
| C. 中小企業與前線員工 | SMB、門市／工廠／醫院前線 | M365 Commercial 席位 **+6%**，增長「主要」來自這兩群 | 較低 ARPU 的 M365 SKU | **席位引擎，不是美元引擎。** Q1 指引已說：SMB／前線新席會拉低整體 ARPU，抵銷一部分 Copilot／E5／E7 的加價 |
| D. 開發者與產業垂直 | GitHub 用戶、Dynamics 客戶、醫療／客服／科學 | GitHub **2.25 億**用戶、Copilot **5,000 萬**使用者；Fortune 500 **>90%** 用 GitHub；客服用量 QoQ **×4** | GitHub Copilot 用量、Foundry／Fabric、Dragon Copilot、Dynamics 代理 | **第二條用量曲線。** 6 月改用量計價後 GitHub Copilot 營收 QoQ **+60%** |

另外還有兩群，對未來展望是配角：

- **消費者**：M365 Consumer 訂閱 +7%、雲收入 +24%；Search／Edge 連續五年拿份額。能提供品牌與 Windows 入口，但營收權重低。
- **PC OEM／Xbox 玩家**：Windows OEM 與 Xbox 正在收縮，FY27 還會再掉。他們不再是緩衝墊。

**10-K 自己寫的增長公式**其實已經點名客人：M365 Commercial「主要受安裝基數增長 + 每用戶平均收入（ARPU）擴張影響」，新用戶要從 **前線員工、中小企業、成長型市場** 來；Azure「主要受 IaaS／PaaS 用量影響」。  
來源：[10-K 業務描述](https://www.sec.gov/Archives/edgar/data/789019/000119312526323660/msft-20260630.htm)、[財報會逐字稿](https://www.fool.com/earnings/call-transcripts/2026/08/07/microsoft-msft-q4-2026-earnings-call-transcript/)

**一句話：** 現在的客人是「已經在 Microsoft 租戶裡的企業」；未來要多賺的錢，不是再找一批全新客人，而是讓同一批人從買 Office 席位，升級成買 Copilot／E7，再為代理人與 token 付用量費。OpenAI 是特殊的超大用量客戶，必須分開看，不能當成「一般企業需求」。

### 8.2 錢花在哪裡

這裡要拆成兩本帳：**客人的錢進 Microsoft 的哪一格**，以及 **Microsoft 自己的錢砸去哪**。商業模式的張力就在這兩本帳對不上的速度。

#### 客人的錢：三層計價，愈來愈往「用量」走

```
傳統：每人每月固定席位（M365 E3/E5）
   ↓ 現在
席位加價：Copilot / E5 / E7（同一個員工付更多）
   ↓ 未來主升息
席位 + 用量：Cowork、GitHub Copilot、Dynamics 客服、資安 Perception
```

| 客人把錢花在 | FY26 量級 | 計價邏輯 | 未來怎麼變 |
| --- | --- | --- | --- |
| Azure 算力、儲存、網路、模型推論 | Azure **>$1,000 億**，+41%；Q4 +43% | 用量（consumption） | 企業自己跑代理人、自訓／選模型，錢留在 Azure，不一定要綁單一 frontier 模型 |
| M365 商業雲（含 Copilot、EMS、資安） | 產品線 **$1,020 億**，+16%；Q4 雲 +16%（調整後） | 席位為主，ARPU 在漲 | 管理層預期 FY27 **全年增速會往上加速**；7 月起 Cowork 已用量計價 |
| Dynamics / 代理人業務流程 | Dynamics **$90 億**，+15%；D365 +18% | 席位 → 席位+用量 | 客服用量 QoQ ×4；650,000 個 MCP actions 讓代理人能進 ERP/CRM |
| GitHub | 含在 Server/cloud | 6 月改用量計價 | Copilot 營收 QoQ +60%，這是「開發者 token 經濟」的先行指標 |
| LinkedIn | **$198 億**，+12% | 招聘訂閱 + 廣告 | Q4 主因是 Marketing Solutions，不是招聘週期 |
| 消費端（Windows／Xbox／Search） | 合計收縮或高個位數 | 授權、硬體、廣告 | FY27 Windows OEM **高雙位數下滑**；Xbox FY27 才預期回正 |

Nadella 在財報會把這套講死了：歷史上的 Office 很窄，Copilot 是「企業級工具 + 每人計價 + 用量計價」，TAM 被打開。E7 把 Copilot、E5、Entra、Agent 365 綁成一包，讓 IT／資安／FinOps 一起買單——這是在賣「治理 token 花費的控制面」，不是再賣一套 Word。

#### Microsoft 自己的錢：2/3 短壽命晶片，1/3 長壽命水泥

| 支出 | FY26 / 展望 | 結構 | 為什麼重要 |
| --- | --- | --- | --- |
| 資本支出 | FY26 現金購置 PPE **$1,159 億**；Q4 **$410 億**（含融資租賃）；日曆 2026 約 **$1,750 億**；Q1 FY27 **>$500 億** | Q4 **約 2/3 是短壽命資產（CPU/GPU）**，其餘才是土地／機房 | 需求若降，可以少買 GPU；水泥比較難停，但佔比較小。這是 Hood 對「會不會蓋過剩」的正答 |
| 未開工機房租賃 | **$3,291 億**，FY27–FY33 陸續開始 | 表外承諾 | 比帳面 $403 億債務更能代表未來固定現金流出 |
| 研發 | **$356 億**，+9% | 算力、AI 人才、資料；全體 headcount 反而 **-2%** | 人沒變多，錢在買訓練／推論產能 |
| 銷售 | $267 億，+4% | 商業銷售 + Copilot 廣告 | 增長不是靠加人推銷 |
| 股東回報 | 股利 $264 億 + 回購 $223 億 | 次於 capex | 資本配置排序：產能 > 股利 > 小幅回購 |

**兩本帳的衝突：** 客人還在從「席位」慢慢走到「用量」，Microsoft 已經先把 GPU 買下去。Q4 公司毛利率掉到 **67%**，Cloud 毛利 **65%**（仍優於預期），主因就是 mix 轉向 Azure + 基礎設施先行。成長故事成立的條件，是客人的用量曲線追上 capex 曲線。

來源：[財報會](https://www.fool.com/earnings/call-transcripts/2026/08/07/microsoft-msft-q4-2026-earnings-call-transcript/)、[EX-99.1 現金流量](https://www.sec.gov/Archives/edgar/data/789019/000119312526323632/msft-ex99_1.htm)

### 8.3 預期如何成長

未來不是一條直線，而是 **三條速度不同的曲線疊在一起**。

| 曲線 | 近況 | FY27 公司指引 / 街市 | 含義 |
| --- | --- | --- | --- |
| 1. Azure 用量 | Q4 +43%；全年 +41% | Q1 約 **+45%** CC；上半年還要再加速 | 這條決定整家公司能不能維持 16–18%。產能一放出就被消化，代表目前是供給約束、不是需求約束 |
| 2. M365 席位加價 | 席位 +6%、雲收入 +16%；Copilot 席 3,000 萬+ | Q1 調整後約 +16%；**全年會加速** | 加速靠 Copilot／E5／E7 與 7 月起的用量產品，不是靠席位暴增。SMB／前線新席會往下拉 ARPU |
| 3. 傳統授權／硬體 | Windows OEM -7%、Xbox -10%、地端 Server 持平 | Windows OEM **高 teens 下滑**；M365 Commercial products 與 Server products **中個位數下滑**；Xbox FY27 回正 | 這條是拖累項。公司總營收 +16–18%，是前兩條在扛第三條 |

街市共識把這三條平均成：FY27 營收 **$3,911 億（+18%）**、FY28 **$4,680 億（+20%）**。公司自己只承諾 FY27「再一年雙位數營收與營業利益」，營業利益率「下降不到 1 個百分點」，且 **FY27 仍自由現金流為正**。

**成長機制（比 CAGR 更重要）：**

1. **同一員工付更多：** E3 → E5 → Copilot → E7。席位不用翻倍，ARPU 就可以讓 M365 維持 teens。
2. **同一工作流程開始燒 token：** Cowork、GitHub Copilot、Dynamics 客服、資安 Perception。這把 TAM 從「人數 × 月費」打開成「任務次數 × 單價」。
3. **企業把學習迴路留在自己租戶：** Nadella 的戰略是模型可替換、記憶與 context 留在 Azure／Fabric。客人選 OpenAI、Anthropic、Mistral 或自訓，錢都還是走 Azure。
4. **產能釋放 = 當季營收：** Hood 說效率提升與提早交付的產能「很快在當季變現」。所以 Azure 增速會隨產能時點上下跳，不代表需求忽冷忽熱。

來源：[Yahoo 共識](https://finance.yahoo.com/quote/MSFT/analysis/)、[財報會 outlook](https://www.fool.com/earnings/call-transcripts/2026/08/07/microsoft-msft-q4-2026-earnings-call-transcript/)

### 8.4 未來要觀察的關鍵數據，以及為什麼

只盯總營收 +18% 沒有用。要看的是「客人有沒有真的在升級計價」以及「Microsoft 有沒有把 GPU 變成可重複的利潤」。

| 優先 | 指標 | 目前水位 | 健康長相 | 一變就代表什麼 | 為什麼是關鍵 |
| --- | --- | --- | --- | --- | --- |
| 1 | **Azure 增速（CC）** | Q4 +43%；Q1 指引 ~45% | 維持 **35%+** 兩個季度以上 | 掉到 25–30% 且不是產能時點問題 | 這是增量的 60%。掉速會直接把公司從「18% 複合」打回低 teens，倍數會切換 |
| 2 | **需求 vs 產能的措辭** | 「demand exceeds available capacity」已連說數季 | 繼續供不應求，或產能追上但利用率仍高 | 改口「供需平衡／現貨價回落」 | 現在的 43% 有一部分是釋放積壓訂單。供給追上後，才知道真實需求斜率 |
| 3 | **Microsoft Cloud 毛利率** | Q4 **65%**，優於預期、YoY 下降；下季「大致持平」 | 守住 **60–65%**，不再單季掉 2–3 個點 | 跌破 60% 且效率說法失效 | 市場最怕 GPU 把雲毛利打穿。毛利比營收更能檢驗「用量有沒有蓋過 capex」 |
| 4 | **RPO／bookings（要看剔除 OpenAI）** | 總 RPO +84%；ex-OpenAI **+25%**；ex-OpenAI bookings +18% | ex-OpenAI 維持 **高 teens–25%** | 總 RPO 大掉或 ex-OpenAI 掉到個位數 | 總數會被一家長約的同比搞到暴衝或暴跌。**分散後的 backlog 才是企業需求** |
| 5 | **M365 Commercial：席位 vs 雲收入 vs ARPU** | 席位 +6%、雲 +16% → ARPU 在做功 | 雲收入持續 **高於席位 8–12 個百分點** | 兩者收斂（都變 +6%） | 這是 Copilot／E5／E7 是否真的在變現。席位來自 SMB／前線，美元來自加價 |
| 6 | **Copilot 付費席 + 用量附件** | 席位 >3,000 萬；Q4 淨增翻倍；Cowork 已用量計價 | 席位續增，且開始披露用量收入 | 席位還在漲但 ARPU 停、或只要試用不大規模部署 | 從 pilot 到全公司部署的證據：>5 萬席客戶 ×7、多數資訊工作者部署的企業 QoQ +75%。這條斷了，E7 故事就停 |
| 7 | **Capex 結構：短壽命 vs 長壽命、FCF** | Q4 約 **2/3 短壽命**；FY26 FCF **$670 億**；FY27 仍承諾 FCF 為正；Q1 capex >$500 億 | 短壽命佔比維持高、FCF 不轉負、capex／營收開始見頂 | 長壽命水泥失控，或 FCF 轉負 | 短壽命 = 可踩煞車。若變成大蓋機房，過剩風險就從「可逆」變成「沉沒」 |
| 8 | **GitHub Copilot 用量營收** | 改價後 QoQ +60% | 用量收入連續兩個季度加速 | 改價後客戶砍席、只用免費額度 | 這是整家公司「席位+用量」模組的實驗室。開發者先走，知識工作者會跟 |
| 9 | **營業利益率** | FY26 **46.8%**；FY27「下降不到 1 個百分點」 | 守住 **45%+** | 掉超過 2 個點 | 公司自己設的底線。跌破代表折舊／COGS 已經吃掉經營槓桿 |
| 10 | **OpenAI 相關收入與應收** | 收入 $241 億、應收 $60 億 | 佔總營收維持 <10%，且 Azure 非 frontier 持續成長 | 應收暴增、或對方自建雲／轉單 | 10-K 已承認這類夥伴「也是 Azure 的重大客戶」，關係改變會動到產能配置與價格 |

**怎麼讀這些數字（決策規則）：**

- **故事仍在：** Azure ≥35%、Cloud GM ≥60%、M365 雲收入比席位快一截、ex-OpenAI RPO 仍雙位數、FCF 為正。
- **故事降速、倍數應下修：** Azure 因產能釋放結束而回到高 20%、Cloud GM 緩跌但 ARPU 還在、capex 仍高 → 變成「貴的優質複合股」，不是破滅。
- **故事裂了：** Azure 與 ex-OpenAI bookings 同時失速、Cloud GM 快速掉、Copilot 席位增但沒有用量／E7、FCF 轉負。那就是 capex 週期走在需求前面。

**觀察節奏：** 每季財報先看 Hood 的四句話——Azure 增速、demand vs capacity、Cloud GM、ex-OpenAI bookings／RPO——再看 Copilot 席位與 capex 短／長壽命比。這四句話比總營收 YoY 更能告訴你，客人有沒有在跟著商業模式走。

**比營收更硬的三個數字：**

1. **商業 RPO $6,780 億，+84%。** 加權 2.3 年；約 30%（~$2,030 億）未來 12 個月認列（近端 +37%，遠端 +112%）。剔除 OpenAI 仍 +25%；當季環比增量全部來自非 frontier。ex-OpenAI bookings +18%。
2. **Copilot 付費席 >3,000 萬**，單季淨增翻倍；>5 萬席客戶數 YoY ×7。GitHub Copilot 6 月改用量計價後營收 QoQ +60%。
3. **Q4 capex $410 億**（現金購置 PPE $358 億），約 **2/3 是短壽命 CPU／GPU**。需求仍大於產能；Q4 多放出的產能「當季就被變現」。

**會計變化，不要誤讀成「減碼」：** FY27 起資料中心與辦公室耐用年數 15→25 年。實質投資不變，但更多機房租賃從「融資租賃（算 capex）」改列「營運租賃（不算 capex）」。日曆 2026 帳面 capex 因此從約 **$1,900 億改口 $1,750 億**。折舊時點變好看，現金流出沒變。FY27 營業利益的好處「很小」。來源：[Fortune](https://fortune.com/2026/07/29/microsoft-azure-100-billion-annual-revenue-earnings-revenue-cloud-ai/)、[Reuters](https://www.reuters.com/business/microsoft-tops-quarterly-cloud-growth-estimates-easing-spending-concerns-2026-07-29/)

**管理層對展望的三句定性：**

1. 需求仍大於供給；效率與提早交付的產能會很快變成當季營收。
2. 商業模式從「每人計價」變成「每人 + 用量」；M365 的 TAM 被打開，不只是再賣一套 Office。
3. 模型可替換、企業資料留在自己租戶；客人選哪家模型，錢都還是走 Azure。

### 9.3 產業趨勢

Microsoft 現在站在三條同時加速的產業曲線上，不是單一「雲端滲透」故事。

**趨勢 1｜雲基礎設施被 AI 重新加速，不是成熟期。**  
Synergy：Q2’26 企業雲基礎設施單季 **$1,434 億、+43%**（八年最快），TTM 約 $5,000 億；連續 11 季加速，近 11 季市場規模翻倍。GenAI 專屬雲 **+165%**。市佔 AWS 28%／Microsoft 20%／Google 15%；前三名 67%。AWS 一年掉 2 個百分點，Google 升 2 個百分點，Microsoft 在 20–21% 橫盤——份額沒爆衝，但是在一個 +43% 的市場裡守住第二。  
[Synergy](https://www.srgresearch.com/articles/q2-cloud-market-passes-143-billion-highest-growth-rate-in-eight-years)、[CRN](https://www.crn.com/news/cloud/2026/cloud-market-share-q2-2026-google-gains-share-as-aws-falls)

**趨勢 2｜AI 支出從「訓練」切到「推論」，對雲廠更有利。**  
Gartner：2026 全球 AI 支出 **$2.60 兆（+47%）**，2027 $3.49 兆；基礎設施佔 >45%。AI-optimized IaaS 2026 **$423 億（+96%）**、2027 $661 億；2026 年推論支出首度超過訓練（55% vs 45%）。推論是持續、分散、跟企業應用綁在一起的用量——這正是 Azure + Copilot + GitHub 的交會點，不是一次買完 GPU 就結束。  
[Gartner AI 支出](https://www.morningstar.com/news/business-wire/20260519405832/gartner-forecasts-worldwide-ai-spending-to-grow-47-in-2026)、[Gartner AI IaaS](https://www.gartner.com/en/newsroom/press-releases/2026-08-10-gartner-forecasts-worldwide-artificial-intelligence-optimized-iaas-spending-to-grow-96-percent-in-2026)

**趨勢 3｜企業軟體從「席位」改成「席位 + 代理人用量」。**  
這不是 Microsoft 獨有，但是它基數最大：M365 商業席 >4.5 億，Copilot 滲透仍約 6–7%。產業方向是：IT 要管 token 花費（FinOps／SecOps），所以會買控制面（E7、Agent 365），不是只買聊天視窗。GitHub「1/3 的 PR 已有 agent」是開發者端已經先走完的樣貌。

**趨勢 4｜供應鏈與單位成本決定誰賺得到錢。**  
GPU／零件漲價、現貨算力仍貴、電力與機房交期是共同約束。Hyperscaler 的應對分化：Microsoft 把 capex 的 2/3 放在短壽命晶片、自研 Maia／Cobalt、用較小模型扛 90% 任務。產業風險是 2027 之後若供給追上、現貨價回落，高 capex 公司會同時面對折舊與價格壓力。

**趨勢 5｜主權雲、多模型、neocloud 在挖邊緣。**  
企業要資料主權與模型可替換（Microsoft 已引 Mistral 進 Sovereign Cloud）。CoreWeave、Oracle、Anthropic 自有雲等「tier two」增速快，專吃 GPU 訓練／推論。這不會立刻動搖三強，但會讓「所有 AI 工作負載都自然留在 Azure」這句話變得沒有以前那麼自動。

**趨勢 6｜PC／遊戲週期與雲脫鉤。**  
Windows 10 結束支援的換機潮已過，零件漲價壓抑出貨；Xbox 在內容重整。產業上這是「成熟硬體週期」vs「AI 雲超週期」分道揚鑣。Microsoft 的 MPC 部門正是這條裂縫的財報表達。

**對 Microsoft 的產業含義：** 大方向對它有利（推論 > 訓練、席位加用量、企業要治理層），競爭也不再是「只跟 AWS 比 IaaS」，而是同時跟 Google 搶雲份額、跟 neocloud 搶 GPU、跟每一家代理人新創搶工作流程。它的優勢是已經有租戶、身份與資料；風險是 capex 節奏必須卡在推論用量真正起來之前。
